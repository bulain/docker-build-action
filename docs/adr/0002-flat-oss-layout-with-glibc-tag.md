# OSS 平铺布局，文件名编码 glibc 版本

产物统一放在 `oss://<bucket>/<prefix>/` 一层下，不再按 el7/el8/el9 分目录；区分信息写在文件名里：`{pkg}-{version}-linux-glibc{X.Y}-{arch}.tar.gz`。

原因：决定二进制能否运行的是 glibc 版本而不是发行版名字，el7 与 el8 的产物名天然不同；平铺让部署脚本只需拼一个文件名，不需要维护目录映射，也避免了同一 glibc 版本在不同 EL 档位下重复出包时的路径歧义。前缀本身参数化，需要分环境时可以改成 `packages/prod` 之类。

代价：OSS 控制台浏览时文件量大且无层级；不同软件、不同版本的产物混在同一目录，只能靠前缀搜索。若将来产物数量增长到难以浏览，再引入按软件分的中间层。
